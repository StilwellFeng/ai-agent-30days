    实战：办公自动化 Agent（文档/表格/邮件）

    把重复的文书工作交给 Agent：读文档、改表格、起草邮件。今天做一个“只读+起草”的安全版。

    🎯 目标：完成一个可用的办公自动化流水线⏱ 60–90 分钟💻 Python

    办公自动化的黄金起步：先做“只读 + 起草”类任务（总结文档、整理表格、起草邮件），让 LLM 输出内容、由你确认后执行。别一上来就让它直接发邮件、删文件。

    典型流水线（参照 Day 18 编排）

    三个“别碰”与三个“先做”

    先做（安全）别碰（等成熟再说）
    总结会议记录 → 输出要点草稿自动发送邮件给客户
    把 Excel 里数据整理成报表/图表删除/覆盖任何原文件
    根据模板起草周报/邮件（人工改后发）访问含敏感信息的系统（先脱敏）

    实现要点

    1. 文件读写用可靠库：处理 Word/Excel/PDF 用成熟的 Python 库（如 python-docx、openpyxl、pdfplumber 等），LLM 只负责“理解内容与生成结果”，不直接操作二进制。具体库名与用法以官方文档为准。
    2. 输出永远是新文件：生成 xxx_总结.md / xxx_草稿.md，绝不覆盖原件。原文件只读打开。
    3. 数据安全：含个人信息/商业机密的文件，先确认是否允许送给外部模型；不允许就走本地模型或脱敏。
    4. 人工确认环：Agent 产出 → 人看一眼 → 确认后才进入“发送/保存”环节。
    💡 用本课程文件练手（零风险）：让 Agent 读本仓库的 lessons/day01.html，总结成 3 条要点并写成 Markdown 新文件——数据是你自己的、操作只生成新文件，安全地体验完整流程。

    ✍️ 今日练习（约 30–60 分钟）

    1. 挑一个你常做的文书任务，明确“输入文件 → 处理 → 输出新文件”三段。
    2. 用你会的工具（或让 AI 助手直接做）跑通一次：输入样例文件 → 得到草稿 → 你人工校对。
    3. 写一份《人工确认清单》：哪些输出必须你看了才能用？

    📌 今日小结

    安全起步只读 + 起草 + 人工确认，先做这三角色 文件铁律原件只读、输出永远是新文件 分工可靠库做文件 IO，LLM 只做理解与生成 数据安全敏感内容先确认能否送外部模型，必要时脱敏
