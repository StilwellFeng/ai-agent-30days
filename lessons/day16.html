    LangChain 核心组件动手用

    不背 API，先建立“组件地图”：Model / Prompt / Tool / Memory / Retriever 各自负责什么、怎么串。

    🎯 目标：看懂一个框架示例在做什么，能改参数⏱ 30 分钟

    LangChain 这类框架的组件，几乎都能对应到我们前两周学过的概念。你已经有地图了，剩下的只是认识框架里每个零件的“牌子”。

    组件地图（概念对应）

    框架组件对应你已学的概念典型用途
    Chat ModelLLM（Day 2）统一调用各家模型
    Prompt Template提示词五要素（Day 4/8）把变量填进固定模板
    Tool工具函数 + 说明书（Day 5/10）包装你的 Python 函数给模型用
    Memory记忆（Day 6）自动管理对话历史

    Agent / Chain规划与编排（Day 13/18）决定执行顺序与循环

    一个典型示例长什么样（结构示意，非可运行）

    # 伪代码：理解“接线”逻辑即可，别背 API
model   = ChatModel(provider="...", model="...")      # 1. 连模型
prompt  = PromptTemplate("你是{role}，请…{task}")      # 2. 提示词模板
tool    = Tool.from_function(get_weather, description=…) # 3. 注册工具
memory  = ConversationMemory()                          # 4. 记忆
agent   = Agent(model=model, tools=[tool], memory=memory) # 5. 组装
answer  = agent.run("北京天气怎么样？")                  # 6. 运行

    看到没有？每一行都是你前两周手工做过的事，框架只是给了现成零件。

    动手建议：从“抄官方示例”开始

    1. 找官方文档里 “Build a simple agent” 之类的入门示例，完整跑通（通常需要 API Key 与安装依赖，先确认你的环境）。
    2. 逐行注释：这一行对应组件地图里的哪一格？
    3. 改 3 个地方：换你的系统提示词、换你的工具函数、换你的问题——跑通即算学会。
    💡 环境准备提示：框架通常用 pip install langchain langchain-openai 这类命令安装，并需要模型 API Key。安装依赖和申请 Key 属于你本机环境的操作，按需进行；示例代码一律以官方文档为准。

    ✍️ 今日练习（约 20–40 分钟）

    1. 打开官方文档的入门示例，把每个组件抄进一张“组件地图”笔记（含你的中文注释）。
    2. 不做任何修改先跑通一次；再只改系统提示词，观察行为变化。
    3. 记录你遇到的两个报错与解法——这是最真实的学习材料。
